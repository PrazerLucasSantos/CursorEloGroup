# Camada 2 — Aplicações (Produto Digital)

**Status:** A definir

Regras de materialização para aplicações e interfaces digitais. Herda tudo da Camada 1 (Fundação Visual).

## Escopo previsto

- **Tokens de UI:** Spacing scale, border-radius, shadows, z-index
- **Estados de componentes:** Hover, active, disabled, error, focus
- **Responsividade:** Breakpoints, grid system, comportamentos mobile
- **Acessibilidade:** Contraste mínimo, focus rings, ARIA patterns

## Como preencher

Criar arquivos específicos por domínio (ex: `tokens-ui.md`, `estados-componentes.md`, `responsividade.md`) com as definições que complementam a fundação visual.
