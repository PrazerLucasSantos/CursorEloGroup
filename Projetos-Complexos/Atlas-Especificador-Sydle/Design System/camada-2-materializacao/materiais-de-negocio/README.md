# Camada 2 — Materiais de Negócio

**Status:** A definir

Regras de materialização para artefatos de negócio. Herda tudo da Camada 1 (Fundação Visual).

## Escopo previsto

- **Slides / Apresentações:** Layouts padrão, margens, hierarquia de texto, templates de slide
- **Documentos:** Estilos de heading, formatação de tabela, cabeçalho/rodapé, espaçamento
- **Artefatos de entrega:** Relatórios, one-pagers, propostas, atas

## Como preencher

Criar arquivos específicos por tipo de artefato (ex: `regras-slides.md`, `regras-documentos.md`, `regras-entregas.md`) com as definições que complementam a fundação visual.
